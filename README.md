# Haoming Li Personal Homepage

🌐 Live Site: https://anakinsnape0104-prog.github.io/Haoming-Li-homepage/

## Overview

This repository hosts my personal academic homepage built with GitHub Pages.

The website serves as a digital portfolio showcasing my academic background, research interests, leadership experience, photography works, and selected projects in finance and data analysis.

The homepage is designed to provide a clean and professional presentation of my profile while remaining lightweight, responsive, and easy to maintain.

---

## Features

* Responsive multi-section homepage
* Chinese / English language switching
* Light / Dark theme switching
* Academic profile and CV presentation
* Research and project portfolio
* Photography gallery
* Contact information and social links
* GitHub Pages deployment
